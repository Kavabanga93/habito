## Регенерация — минимальный точечный список

### 🔴 Tier 1 (обязательно) — 2 клипа
Уравнять 5 фигур Домов: у всех должно быть действие, как у #9/#15/#18.

Движок: **Seedance 2.0, genre=action**, 9:16, 1080p. Промпт = Style Anchor + субъект-блок Дома из `docs/04_Visual_Style_Guide.md`, лицо спрятано (капюшон/спина/профиль).

### 🟡 Tier 2 (опционально)

- По желанию — разнообразить камеру в 1-2 environment-наездах (или добавить параллакс на монтаже — дешевле).

**НЕ нужно** трогать остальные 15 — они держат уровень.

## Схема переходов (motivated, WoW-style) — без перегенерации

Принцип: переход рождается из того, что уже есть в конце клипа (вспышка/чёрный/глаз/цвет),
+ overlay-элемент (искры/дым/свет) проносится через стык, + speed-ramp, + удар-whoosh в звуке.

**Язык по типу шота (роль = единый приём, тип = разный):**
- **Sigil** — быстрый снап + короткая вспышка цвета Дома.
- **Environment** — боковой трек / параллакс / кран (НЕ наезд), выход whip-pan или в чёрный.
- **Figure** — наезд ИЛИ жест-действие, выход motivated-броском в следующий Дом.

**Уникальный «замок» на стыке Домов (чтобы 5 переходов не были одинаковы):**
- Federation → Vorkhan: цветоперетёк синий→красный (уже baked в #6).
- Vorkhan → Mercanti: меч-луч #9 заливает в золото #10 (whip).
- Mercanti → Vergent: gold zoom-blur #12 → зелёный блум (match по свечению).
- Vergent → Ophus: фиолетовый сдвиг #15 → фиолетовая вспышка #16.
- Ophus → Architects: глаз в темноте #18 → глаза Архитекторов #19a (match по мотиву «глаз»).

**Мотив-рифма «глаз»** (#13 зелёный → #16 фиолетовый → #18 → #19 глаза Архитекторов) —
оставить как сквозную тему «Astro смотрит в ответ»; кульминация — #19b, где 5 цветов Домов
сходятся в звезду. Сюда — лого ASTRO (нужен PNG с прозрачным фоном).
